# Tableau-Portfolio.
Projet-1-Sales-Analysis
Commercial Sales Performance Analysis – Tableau

Project Overview

This project focuses on analyzing commercial performance through sales, profitability, customer behavior, and delivery performance.

The objective is to design interactive dashboards to monitor business performance, identify trends, and support data-driven decision-making.

Tools Used

* Tableau

Key Activities

* Creation of 15 Key Performance Indicators (KPIs).
* Development of calculated fields and custom measures.
* Design of 3 interactive dashboards.
* Analysis of sales performance and profitability.
* Customer behavior analysis.
* Monitoring of delivery times and performance.

Skills Demonstrated

* Data analysis and exploration.
* KPI development and monitoring.
* Data visualization.
* Interactive dashboard design.
* Business performance analysis.
* Decision support.
